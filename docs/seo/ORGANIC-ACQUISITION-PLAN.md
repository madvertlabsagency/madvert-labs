## 10. Measurement plan

| Question | Where | How |
|---|---|---|
| Are pages indexed? | Search Console → Pages; Bing Webmaster → Site Explorer | Weekly for 4 weeks after publishing |
| Which queries and pages gain impressions? | Search Console → Performance, filter by page and by country (PK, US, GB, SA, AE) | Compare 28-day windows |
| Do AI answers mention Madvert Labs? | Fixed prompt list (`docs/AI-VISIBILITY.md`) | Monthly; record mention, description and cited URL |
| AI referral traffic | GA4 → Traffic acquisition, session source contains chatgpt.com, perplexity.ai, copilot, gemini | Monthly |
| Organic leads | GA4 key events `contact_form_complete`, `lead_magnet_conversion`, `calendar_booking_complete`, filtered by Organic Search | Weekly |
| CTA engagement | GA4 `strategy_call_click` by label (shows which page and position drove the click) | Weekly; clicks are not bookings |
| Qualified inquiries and confirmed bookings | CRM (GoHighLevel): source = organic, stage = qualified / booked / won | Monthly; the real success measure |
| Technical health | `/ops/seo` weekly audit | Fix any error the same week |
